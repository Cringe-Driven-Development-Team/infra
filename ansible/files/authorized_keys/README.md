# Публичные ключи команды

Сюда кладём публичные ключи (`*.pub`, один файл = один человек с узнаваемым именем,
например `yarik.pub`) всех, кто заходит на стенд под пользователем `deploy`.

Роль `users` устанавливает их все в `~deploy/.ssh/authorized_keys` с `exclusive: true`:

- новый участник → PR со своим `.pub` → `ansible-playbook site.yml`;
- ушедший участник → удалить его `.pub` → `ansible-playbook site.yml`.

Серверы пересоздавать не нужно. Приватные ключи сюда коммитить нельзя.
