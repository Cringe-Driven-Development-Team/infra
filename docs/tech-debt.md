## Ansible

- **Caddy ставится на хост через apt, а по схеме MVP он внутри Docker Compose.** С Caddy на хосте Go API
  пришлось бы публиковать на `127.0.0.1:8080`, а спека (`docs`, `2026-09-29-mvp-single-vps-design.md`, §4) требует,
  чтобы Go API и Postgres были видны только во внутренней сети Compose. Решение: в задаче деплоя
  ([backend#2](https://github.com/Cringe-Driven-Development-Team/backend/issues/2)) Caddy переезжает в Compose
  вместе с приложением (порты 80/443, volume для сертификатов), роль `caddy` из `site.yml` удаляется.
  Делать до роли приложения.
